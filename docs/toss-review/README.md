## 다시 만들기

`shots/` 에 캡처를 채워 넣고:

```bash
node docs/toss-review/build.js
```

캡처가 있는 슬라이드는 이미지로, 없는 슬라이드는 "무엇을 어떻게 찍어야 하는지" 적힌
자리표시자로 들어갑니다. 테스트 계정이 정해지면 함께 넘기면 표지에 박힙니다:

```bash
TOSS_TEST_ID=아이디 TOSS_TEST_PW=비밀번호 node docs/toss-review/build.js
```

## 캡처 규칙 (가이드 4쪽)

전부 지켜야 심사가 정상 진행됩니다.

1. **북마크바 숨기기** — 크롬에서 `Ctrl+Shift+B`
2. **주소창의 도메인이 보이게** — 전체화면 캡처(`PrtSc`)로 찍습니다. 영역 캡처(`Win+Shift+S`)로
   본문만 잘라내면 도메인이 빠져 반려됩니다.
3. **작업표시줄 시계가 함께 나오게** — 카드사가 시간 흐름으로 조작 여부를 봅니다.
   그래서 캡처 순서대로 실제로 클릭해 가며 찍어야 시각이 자연스럽게 이어집니다.
4. 창은 최대화하고, 개인 정보(다른 탭 제목, 알림)는 정리한 뒤 찍습니다.

## 참고

- 화면 기본 언어는 베트남어지만 `/service`, `/refund`, `/terms`, `/privacy`, 주문서는
  한국어로 작성돼 있습니다. 홈 하단 사업자 정보는 베트남어 화면에서도 한국어 라벨을
  함께 보여주도록 고쳤습니다(`i18n.ts` 의 `biz.*`).
- 상품 금액의 정본은 DB(`study_issuance_pricing.unit_price`)입니다. 어드민에서 금액을
  바꾸면 상품 페이지·주문서·결제 승인 금액이 함께 바뀝니다.
